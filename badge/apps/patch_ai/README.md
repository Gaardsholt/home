# Patch AI

Meet Patch AI, your cheerful Bestseller Tech denim robot companion on the GitHub Universe 2026 badge.

## Usage

Launch Patch AI from the badge launcher menu. Patch AI greets you with a cheerful wave, bobbing motion, blinking stitched button eyes, and a glowing power button.

### Controls

- **Select**: Trigger an energetic greeting wave and cheerful speech dialogue.
- **Left / Right**: Cycle mood and animation modes (Cheerful Wave, Happy Dance, Standby Nap).
- **Back**: Exit back to the badge launcher menu.

No extra hardware, network connection, or configuration secrets are required.
